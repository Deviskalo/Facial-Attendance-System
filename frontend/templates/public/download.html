RUN FROM SOURCE

Use the desktop launcher

  1. Install Python 3.10 or newer.
  2. Download or clone the project source.
  3. Run setup.bat, then run desktop.bat.
  4. On first launch, allow internet access to download the face-recognition model. WebView2 Runtime is also required.

The desktop launcher installs its optional dependencies in the project-local virtual environment.

BUILD AN INSTALLER

Build locally

On a Windows x64 build machine with Python 3.10 or newer, run:

.\setup.bat
.\packaging\build_windows.bat

The script creates an application directory under release\windows. Install Inno Setup 6 and add ISCC.exe to PATH to compile an installer. Sign the installer before distribution.

The installer does not include application data or the InsightFace model. Model files and third-party components have separate terms; review their licenses and permitted-use conditions before deployment or redistribution.

PUBLISH A RELEASE

From signed build to GitHub download

  1. Update AppVersion in packaging\FaceAttendanceKiosk.iss, then build on Windows with setup.bat and packaging\build_windows.bat.
  2. Sign release\windows\FaceAttendanceKiosk\FaceAttendanceKiosk.exe with your organization’s trusted code-signing certificate, then compile the installer with ISCC.exe packaging\FaceAttendanceKiosk.iss so the signed app is included.
  3. Sign release\installer\FaceAttendanceKiosk-Setup-<version>-x64.exe. Use SHA-256 for the file digest and an RFC 3161 trusted timestamp. Keep the private key out of the repository.
  4. Verify both Authenticode signatures and the publisher in Windows, then test install, launch, camera access, upgrade, and uninstall on a clean Windows machine.
  5. Commit and push the version change. Create and push a matching version tag, for example v1.2.0.
  6. On GitHub, create a release for that tag and upload the signed installer with a filename containing Setup and ending in .exe. Add release notes describing changes and known requirements.

With Microsoft SignTool available, the signing commands follow this pattern (replace the paths and use your trusted timestamp provider):

signtool sign /fd SHA256 /tr https://timestamp.digicert.com /td SHA256 /a "path\to\FaceAttendanceKiosk.exe"
signtool verify /pa /v "path\to\FaceAttendanceKiosk.exe"

After compiling, repeat those commands for the FaceAttendanceKiosk-Setup-<version>-x64.exe installer and verify it as well.

After a published release is available, this page automatically links to the installer asset in the latest non-draft, non-prerelease GitHub release. If no matching installer is attached, it links to the releases list instead.

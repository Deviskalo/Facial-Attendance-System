ABOUT THE PROJECT

Attendance tools that run where you do.

Face Attendance is a self-hosted application for workplace attendance workflows. It combines a camera kiosk with guided enrollment and password-protected administration.

How it works

  1. An administrator creates the admin password and configures attendance settings.
  2. People are enrolled using a guided five-pose capture and quality checks.
  3. The kiosk analyzes camera frames locally and records check-in or check-out events in the local database.
  4. Administrators review logs, export records, and create or restore local backups.

Local-first by design

The application uses FastAPI, SQLite, OpenCV, and InsightFace. Normal attendance and face processing run on the host machine; the application does not require a hosted service for normal operation. Initial setup may need internet access to install dependencies and download the recognition model.

Deployment matters

The default server is intended for an access-controlled local network, not direct public-internet exposure. Camera access in a browser requires a secure context such as HTTPS or localhost. Read the privacy information and terms before putting the system into use.

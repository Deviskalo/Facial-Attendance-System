PRIVACY INFORMATION

Know what is collected and where it lives.

This page describes the application's default behavior. The organization operating the system is responsible for its deployment, notices, consent, retention, and legal compliance.

Information the system stores

Depending on how it is used, the application stores employee names, IDs and departments; attendance events and correction history; administrator settings; face images captured during enrollment; and face embeddings used for matching. Face images and embeddings are sensitive biometric data.

Where information is stored

Browser/LAN mode stores data in the application's data/ directory on the server host. Desktop mode stores data in the current user's application-data directory (on Windows, %LOCALAPPDATA%\FaceAttendanceKiosk). Local ZIP backups can contain the database and biometric face assets. Anyone with access to these files may access sensitive information.

Processing and network access

During normal operation, camera frames are sent from the kiosk browser to the application server for local face processing. The application is designed to process attendance locally and does not require a hosted service. Internet access may be used during setup to install software dependencies and obtain the face-recognition model. If an operator configures a reverse proxy, remote access, or other integrations, those systems may affect how information is transmitted.

Camera and browser data

The kiosk requests camera access while in use. The browser controls the permission prompt. The application also uses a session cookie to support administrator sign-in. The public information pages do not require sign-in.

Retention, access, and deletion

The organization operating the system should define who can use the admin account, how long records and biometric data are kept, how they are deleted, and how backups are protected. The app provides local backup and restore features; deleting or replacing live data does not automatically remove copies kept in backup archives.

Questions and updates

Contact the organization that operates this installation for questions about a person's data or to request access or deletion. This page describes software behavior and is not legal advice or a substitute for an organization-specific privacy notice.

Last updated: October 13, 2026

Before deployment

Obtain appropriate consent and authorization. Restrict access to the host and network, secure backup archives, and establish a lawful retention and deletion process.
